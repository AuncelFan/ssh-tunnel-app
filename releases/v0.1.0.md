# ssh-tunnel 0.1.0

Tauri 2 + React + Rust desktop SSH tunnel manager.

## Downloads / 下载

- **Windows x64**: `windows-x64.exe` is portable; `windows-x64-setup.exe` installs for
  the current user. Microsoft Edge WebView2 is required; the installer can download it.
- **macOS 11+**: `macos-universal.dmg` contains both Apple Silicon and Intel code.
- **Linux x64**: `.AppImage` and `.deb` packages, built on Ubuntu 22.04.
- `SHA256SUMS` lists all package and manifest checksums. Platform manifests record
  the exact source commit, version, file sizes and SHA-256 hashes.

Windows 下载独立 EXE 或安装包；macOS 下载 Universal DMG；Linux 下载 AppImage 或 DEB。
请使用 `SHA256SUMS` 校验下载文件。

## Features / 功能

- L/R/S forwarding, ordered jumper chains, password/key/agent authentication.
- First-trust and changed-host-key confirmation, configurable reconnect policies.
- Custom and default-jumper groups with one-click start/stop.
- Compact jumper-prefixed tunnel rows, detailed forwarding errors and per-tunnel logs.
- Live transfer rates and rolling last-hour upload/download volumes.
- SSH config/command import, configuration backups and directory relocation.
- Simplified Chinese/English, light/dark themes, tray and login startup.

支持 L/R/S 三种转发、有序跳板机链、主机密钥确认、自定义重连策略、分组启停、
近一小时流量、详细错误与日志、配置导入导出，以及中英文和明暗主题。

## Security and platform notes / 安全与平台说明

- Windows executables are not Authenticode-signed. macOS uses an ad-hoc signature,
  not an Apple Developer ID signature, and is **not notarized**. Windows SmartScreen
  and macOS Gatekeeper may warn or block execution. Do not disable system-wide
  security protections. A trusted local source build is an alternative.
- CI runs Rust/React tests on all three platforms and native WebView2 regression on
  Windows. macOS/Linux desktop interactions are not covered by that Windows test.
- Configuration and exports contain plaintext credentials. Protect their permissions.
  Traffic history is in-memory and resets when the application exits.

本版本没有商业代码签名；macOS 仅临时签名，未经过 Apple 公证，系统可能警告或阻止运行。
请勿为此关闭系统全局安全防护。配置文件包含明文凭据，请妥善保存。
