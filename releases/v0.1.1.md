# ssh-tunnel 0.1.1

## Changes / 更新

- Tunnel rows now expose start/stop, test, diagnose, edit, duplicate, delete and
  details as compact icons with hover labels, plus an auto-start switch.
- Duplicated tunnels keep their original names.
- Clone an entire group to another jumper from the group header. Choose the new
  group name and target jumper; the first hop is replaced while subsequent hops,
  tunnel names and port mappings are preserved. Clones remain stopped with
  auto-start off to avoid competing listeners. The whole group is saved atomically.
- Changing auto-start or cloning a group does not interrupt existing connections.
- Navigation now reads Tunnels, Jumpers, Logs, Overview, Settings.
- Added regression coverage for list actions, cloning, failed writes, connection
  continuity, and compact layouts in Simplified Chinese/English and light/dark themes.

隧道列表右侧集中显示启停、测试、诊断、编辑、复制、删除与详情图标，悬浮查看说明，
并可直接切换自动启动。复制隧道保留原名。分组标题旁新增整组克隆，选择目标跳板机与
新分组名称后，仅替换每条隧道的首跳，保留后续链路和端口映射；新隧道保持停止并关闭
自动启动。切换自动启动或克隆分组不会中断现有连接。概览移到设置之前。

## Downloads / 下载

- **Windows x64**: portable EXE and current-user NSIS installer. Requires Microsoft Edge WebView2.
- **macOS 11+**: Universal DMG for Apple Silicon and Intel.
- **Linux x64**: AppImage and DEB built on Ubuntu 22.04.
- Use `SHA256SUMS` to verify downloaded files. Platform manifests identify the
  source commit, version, file sizes and SHA-256 hashes.

## Security and platform notes / 安全与平台说明

- Windows executables are not Authenticode-signed. macOS uses an ad-hoc signature
  and is not notarized. Windows SmartScreen or macOS Gatekeeper may warn or block
  execution. Do not disable system-wide security protections.
- Packages contain the application only. Local configurations, credentials,
  private keys and developer test evidence are not release attachments.
- Configuration exports contain plaintext credentials. Keep exports private.
- Windows WebView2 regression does not establish macOS/Linux desktop acceptance.
