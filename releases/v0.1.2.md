# ssh-tunnel 0.1.2

- The GUI and CLI share configuration, running tunnels and host-key decisions. Keep `ssh-tunnel.exe` and `ssh-tunnel-cli.exe` together. Use `ssh-tunnel-cli agent-help` for automation guidance and `ssh-tunnel-cli --help` to discover commands, JSON arguments and exit codes.
- Clone a group or selected tunnels into the target jumper’s default group. Clones keep their names and port mappings and start with auto-start off.
- Select multiple tunnels for deletion. Deleting a jumper previews dependent tunnels across all hops and checks the confirmed selection before deleting them together.
- The connection test now includes diagnostics in the same report.
