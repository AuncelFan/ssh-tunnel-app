# Application icons

The minimal tunnel icon uses opposing arrows through a portal.

- `appicon-raw-1024.png`: high-resolution source artwork.
- `appicon.png`: application icon used by Tauri.
- `windows/icon.ico`: multi-resolution Windows icon.
- `icon.icns`: macOS icon generated from the same source artwork.

Preserve transparency when exporting artwork. `bin/` contains locally staged release
executables and checksums and is excluded from source control.
